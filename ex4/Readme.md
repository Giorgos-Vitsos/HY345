Η βασική δυσκολία της εργασίας ήταν να αποφευχθεί το starvation κάτι που τελικά δεν κατάφερα να λύσω πλήρως.Το bzImage που παραδίδεται προέρχεται από την τελευταία έκδοση του κώδικα και περιέχει την τρέχουσα υλοποίηση του αλγορίθμου ltf.
Η υλοποίηση δεν είναι ολοκληρωμένη όμως, δείχνει τη βασική ιδέα και τη λογική του LTF scheduler.Αν είχα περισσότερο χρόνο, θα προσπαθούσα να οργανώσω τα LTF tasks σε ξεχωριστή λίστα ώστε ο scheduler να είναι πιο γρήγορος και να βρω έναν τρόπο να λύσω το starvation των υπόλοιπων διεργασιών.
